# Nära — Nivika concept demo

A standalone, clickable concept for a verified local reuse marketplace for Nivika residential tenants in Värnamo.

## Important

This is an independent concept demo. It is not an official Nivika service and has not been approved or commissioned by Nivika. All listings, people, interactions and pilot targets are fictional examples.

A real pilot must read the permitted property from Nivika's current contract and property records. The demo names Falken 25 only because Nivika publicly identifies it as a residential property. No payment, public messaging, external users or backend data collection is included.

## Run locally

Open `index.html` in a modern browser.
